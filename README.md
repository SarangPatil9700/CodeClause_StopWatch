## ⏱️ CodeClause Stopwatch  

### 🌟 Overview  
This is a **simple and responsive stopwatch** web application developed using **HTML, CSS, and JavaScript**. It features a clean, minimalistic **dark theme** with easy-to-use controls for **starting, stopping, and resetting** the timer. The stopwatch accurately measures time in **hours, minutes, and seconds**, making it a handy tool for various tracking purposes.

### ✨ Features  
✔ **Start, Stop, and Reset Functions** – Control the stopwatch with intuitive buttons.  
✔ **Real-Time Timer Display** – Shows time in the format `HH:MM:SS`.  
✔ **Minimalistic Dark UI** – Elegant and distraction-free user interface.  
✔ **Fully Responsive** – Works seamlessly on both desktop and mobile browsers.  
✔ **Efficient JavaScript Implementation** – Uses `setInterval()` for real-time updates.
